# Unemployment Analysis with Python

## Project Overview
This project analyzes unemployment trends in India using Python. The analysis focuses on unemployment rates, trends, monthly patterns, and the impact of COVID-19.

## Objectives
- Analyze unemployment rate trends
- Perform data cleaning and exploration
- Visualize unemployment trends
- Analyze the impact of COVID-19
- Identify monthly patterns and trends
- Generate key insights from the data

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The project uses the **Unemployment in India** dataset from Kaggle.

## Key Analysis
- Unemployment rate trend analysis
- COVID-19 impact analysis
- Monthly unemployment pattern analysis
- Highest and lowest unemployment rate identification
